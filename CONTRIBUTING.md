# Contributing

Thank you for helping keep this list useful.

## What belongs here

- Open-source projects about sauna, banya, steam rooms and related bathing: integrations, libraries, controllers, calculators, simulations.
- Open data, or tools for getting at it.
- Standards, societies, heritage listings and reference material from a clearly identified publisher.
- Peer-reviewed research, linked by DOI.

## What does not

- Shops, product pages, affiliate links, "best sauna" roundups and other marketing.
- Health claims. A paper may be listed by its title; the description stays neutral.
- Dead, parked or login-only pages.
- Projects with no description, no README, or no sign that they work.

## How to add a link

1. One suggestion per pull request.
2. Use this format: `- [Name](https://example.com/) - One plain sentence that ends with a period.`
3. Put it at the end of the right section. Note the language if the page is not in English.
4. In the pull request, say what the link is and how you checked it (opened it, read the README, ran it).
5. For anything that switches a heater, say what safety features it keeps.

## Removing a link

Open an issue or a pull request if a link is dead, has changed owner, or no longer matches its description.
